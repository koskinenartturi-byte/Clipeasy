# ClipEasy V0.2

Selainpohjainen video- ja kuvaeditorin prototyyppi.

## Ominaisuudet
- videoiden ja kuvien lisääminen
- monileikkeinen aikajana
- leikkeiden trimmaus ja järjestely
- nopeus 0,5–2x
- äänenvoimakkuuden säätö käyttöliittymässä
- suodattimet
- tekstikerros
- kuvasuhteet 9:16, 16:9 ja 1:1
- kumoa/tee uudelleen
- selainpohjainen WebM-vienti

## Käyttö
Avaa `index.html` selaimessa tai julkaise tiedostot GitHub Pagesissa.

## V0.2:n rajaukset
Vienti on WebM-muotoinen. MP4-vienti, varma ääniraidan miksaus, automaattinen leikkaus ja pilvitallennus kuuluvat seuraaviin versioihin.
